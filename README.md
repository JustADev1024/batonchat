# BATONCHAT

Красивая статическая страница с надписью BATONCHAT.

## Описание

Этот проект содержит простую и стильную одностраничную веб-приложение с анимациями и интерактивными эффектами.

## Файлы проекта

- `index.html` - Структура страницы
- `style.css` - Стили и анимации
- `script.js` - Интерактивные эффекты

## Особенности

✨ Красивые градиентные фоны  
🎨 Плавные анимации  
🖱️ Интерактивные эффекты при наведении и клике  
📱 Адаптивный дизайн  

## Запуск

Просто откройте файл `index.html` в вашем браузере!
